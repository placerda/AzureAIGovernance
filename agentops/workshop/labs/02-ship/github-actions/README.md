# Ship with GitHub Actions

[All labs](../../README.md) | [Shared Ship lab](../lab.md)

Choose this path when the session uses a GitHub repository and GitHub Actions.
It is an alternative to Azure Pipelines, not an additional lab.
Both paths produce the same release checklist.

## Start the activity

Complete [Ship pre-work](../../../pre-work/README.md#ship).
The instructor supplies `agentops-ship-review.zip` with blocked and accepted
GitHub Actions runs, evaluation reports, approval and post-deployment results.
Open the package's README, then follow the
[shared release review](../lab.md#available-preparation-review).
If the supplied links belong to the other platform, ask for the package
assigned to this session rather than switching tracks.

**Current scope:** review saved results. The full runnable workflow is still
being developed; this folder does not contain a pipeline to execute.
The [GitHub Actions outline](../lab.md#track-a-github-actions) describes
the planned platform-specific topics.

Instructors follow [Teaching Ship](../../../instructor-guide/ship.md)
to select the track and prepare the class.
